RAG 진단 콘솔
체류정책봇 · Production 진단 콘솔

외국인 비자·체류 RAG 품질 개선 대시보드

문서 수집·청킹·임베딩·검색·리랭킹·답변 생성 전 구간의 품질 지표를 확인하고, 개선 전후 성능을수치로 비교하는 관리자 콘솔입니다

Tier 1 · 핵심 개선 흐름

5개
flow_1
RAG 파이프라인 진단 및 실패 원인 분류

7단계 파이프라인 처리량·지연·실패 지점을 한 화면에서 확인합니다

flow_2
평가셋 구축 및 기준 성능 측정

다국어 200건 평가 문항과 기대 정답을 관리하고 기준 성능을 기록합니다

flow_3
질의 재작성 및 하이브리드 검색 개선

벡터·키워드·메타데이터 가중치와 다국어 동의어 규칙을 조정합니다

flow_4
근거 기반 답변 생성 및 출처 인용 개선

검색된 공식 근거 내에서만 답변을 생성하고 보류 분기를 관리합니다

flow_5
개선 후 성능 측정 및 회귀 테스트

개선 전후 지표를 비교하고 회귀 실패 케이스 재현 방법을 기록합니다

Tier 2 · 보조 운영 흐름

4개
flow_6
공식 문서 수집 범위 확장 및 메타데이터 정비

법령·고시·안내서 출처를 추가하고 메타데이터를 정규화합니다

flow_7
reranker 적용 또는 재정렬 로직 개선

리랭커 A/B 결과와 스코어링 개선안을 비교합니다

flow_8
운영 가이드 및 인수인계 문서 작성

환경설정·프롬프트·평가 코드 수정 가이드를 정리합니다

flow_9
end-to-end 대표 질문 테스트

질의 입력부터 출처 표시까지 전 구간을 시나리오로 검증합니다

Tier 3 · 부가 관리

1개
flow_10
외부 LLM API·모델 비용 정산

API 사용량과 비용 분담 현황을 모니터링합니다
