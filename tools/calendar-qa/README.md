# 사내 캘린더 QA 환경

로그인과 운영 DB 없이 워크룸 사내 캘린더(`#calendar`)를 모의 데이터로 띄워 확인하는 도구입니다. 운영 DB·운영 푸시에는 전혀 닿지 않습니다.
모의 데이터의 이름은 모두 가상입니다(이 레포는 GitHub Pages 로 공개됩니다 — 실명·연락처·비밀값을 넣지 마세요).

## 띄우기

```bash
(cd dashboard && npm install)          # 처음 한 번 (esbuild)
node tools/calendar-qa/build.mjs --serve
# → http://127.0.0.1:8791/index.html#calendar
```

- 데이터는 **브라우저 탭마다** 저장됩니다(새로고침해도 유지, 새 탭은 처음 데이터).
- 주소 옵션: `?as=1~7` 로그인한 사람(팀원 목록 순서, 기본 2) · `?n=3~7` 팀원 수 · `?reset=1` 초기화 · `&empty=1` 빈 캘린더
- 화면 왼쪽 아래 **QA** 버튼: 사람 바꾸기, 데이터 초기화, **알림 미리보기**(운영 함수와 같은 판단 코드 `plan.ts` 로 받는 사람별 제목·본문 계산)

## 기본 데이터 (여는 날 기준 · '+n'은 n번째 평일)

| 날 | 상황 |
|---|---|
| 오늘 | 김가람 오후반차, 최라온 서울숲(개인), 11:00 장애 회의(전화), 14:00 수주 미팅(화상) |
| +1 | 이날만 시청역2호점 전원 출근, 김가람·이나래 14:00~16:00 대면 미팅(외근 표시) |
| +2~+3 | 박다온 연차 2일, 이나래 재택(개인), 그날만 서울숲(시청역 공사), 제안서 마감 |
| +2 · +4 | 다른 장소(직접 입력): 김가람 판교로 바로 출근 · 팀 전체 성수동 라마바빌딩(고객사 워크숍) |
| +6 · +7 | 팀 근무지에 오는 사람 없음: 전원 개인 재택(→ '재택', 휴가 1명 포함) · 제각각 재택/서울숲/외근(→ '각자 근무') |
| 다음 주~ (달력 날짜) | 최라온 연차 3일, 협력사 미팅, 박다온 종일 대면 교육, 매주 주간 회의 |

주간 패턴은 월·화·목·금 시청역 / 수 재택입니다. '평소 ○○' 표시는 그날의 요일에 따라 달라집니다(수요일이면 '평소 재택').

## 자동 점검

Playwright(`playwright-core`)와 Chromium 이 필요합니다. 다른 프로젝트에 설치돼 있으면 경로를 넘기면 됩니다.

```bash
node tools/calendar-qa/build.mjs --serve &      # 서버 먼저
export PW_CORE=/path/to/node_modules/playwright-core   # 없으면 require('playwright-core')
for t in tools/calendar-qa/tests/*.cjs; do echo "== $t"; node "$t" | grep -E "PASS|FAIL|ERR" | grep -cv PASS; done
```

### 알림 권한 흉내 (주소 옵션)
- `?perm=denied` 차단 · `?perm=granted` 허용 · `?perm=default` 아직 안 물어봄
- `?app=1` 설치한 앱 창(맥·윈도우 앱, 아이폰 홈 화면 앱)처럼
- `?ua=mac-chrome|mac-safari|win-chrome|iphone|android` 기기·브라우저 흉내
- 예: `index.html?perm=denied&app=1&ua=mac-chrome#calendar` → 🔔 → 맥 크롬 앱 창의 차단 해제 안내
- `?lat=800` 읽기마다 800ms 지연(느린 네트워크)
