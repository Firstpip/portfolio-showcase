# 📱 모드: mobile-web (모바일 앱 공고 폴백)

이 공고는 **모바일 앱**을 요구했다. 웹으로 시연하되, 보는 사람이 곧바로 "앱" 으로 인지해야 한다.

화면 폭을 390px 로 가두고 가운데 세우는 **폰 프레임은 시스템이 CSS 로 이미 넣는다.** 너는 그 안에 들어갈 내용을 모바일답게 만들면 된다. 프레임을 직접 그리려 하지 마라 (중복 프레임이 생긴다).

## 반드시 지킬 것

- **하단 탭바 내비게이션.** 사이드바·상단 가로 메뉴 금지. flow 가 5개를 넘으면 주요 4개만 탭에 두고 나머지는 "더보기" 탭 안의 목록으로 넣는다.
- **한 화면에 한 가지 일.** 데스크톱식 2단·3단 레이아웃 금지. 세로 스택만 쓴다.
- **터치 타깃 최소 44px 높이.** 버튼·리스트 행·탭 모두.
- **가로 스크롤 금지.** 표는 카드 리스트로 바꾼다. 넓은 차트는 폭에 맞춰 축소하거나 핵심 지표 숫자로 대체한다.
- **상단 앱바**: 현재 화면 제목 + 필요 시 뒤로가기. 헤더에 많은 걸 넣지 마라.
- 폼은 한 줄에 한 필드. 라벨은 필드 위에.
- 리스트는 카드 또는 구분선 있는 행. 각 항목은 탭 가능해 보이게.

## 하면 안 되는 것

- `min-width` 로 폭을 강제하거나 `width: 100vw` 를 쓰는 것 (프레임을 깨뜨린다)
- 데스크톱용 테이블(`<table>` 다열), 사이드바, 마우스 hover 에만 의존하는 인터랙션
- 폰 목업 이미지·기기 테두리를 직접 그리는 것 — 시스템 프레임과 겹친다

## 톤

실제 앱처럼 보여야 한다. 여백을 넉넉히 주고, 화면당 정보 밀도를 데스크톱보다 낮춘다. 하단 탭바는 항상 보이게 고정(`fixed`)하고, 본문 하단에 탭바 높이만큼 여백을 준다.
